# 簡介

MikaUI 是一套 Unity UGUI 管理框架，提供統一的 UI 建立與回收流程，幫助你管理視窗及其子 UI 的生命週期。

假設你正在製作一個商店。玩家可以開啟商店、查看商品詳情，最後關閉視窗。隨著功能增加，你可能需要在不同腳本中協調關閉順序、清理狀態，並確保商品詳情不會在商店關閉後留下來。

MikaUI 讓你在建立 UI 時，同時描述它的存活範圍與回收關係。開啟商店的程式可以把「建立、等待操作、回收」放在同一段流程裡；加入商品詳情後，商店關閉時的子 UI 回收順序也交由框架處理，減少各個腳本之間的協調。

我們會用這個商店作為範例，逐步介紹它的用法。

## 基本用法

下面是一個開啟商店的範例，假設 manager 與 prefab 已經準備好：

```csharp
using (var token = await uiManager.Create<UI_ShopProduct>(sortingOrder: 0))
{
    await token.UI.ShowAsync(product);
}
```

`Create` 建立商店，並回傳包含 UI 的 token。透過 `token.UI`，我們可以把商品資料交給商店。

這裡的 `ShowAsync` 是範例自訂的非同步方法：它顯示商品，並等待玩家關閉商店。等待結束後，程式離開 `using` 區塊，MikaUI 就會回收商店。

這個例子展示了兩個核心功能：

- **統一建立**：透過 manager 建立 UI，使用相同的管理流程。
- **生命週期管理**：透過 token 表達 UI 的存活範圍，結束時交由框架回收。

你暫時只需要理解這段流程。快速上手會先帶你操作 demo 的商店，再閱讀對應的程式，了解這段流程如何運作。

## 子 UI

商品詳情可以單獨關閉，也應該在商店關閉時一起結束。

MikaUI 允許你在建立詳情時指定商店為 parent。回收商店時，框架會先回收它的子 UI，再回收商店，讓這個關閉順序由同一套流程處理。
